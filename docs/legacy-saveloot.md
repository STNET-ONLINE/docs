# Сохранение прогресса (Legacy)

![saveloot.lua](./Image_saveloot.png)

**Сохранение прогресса (`saveloot.lua`)** - это специально разработанный сценарий для **NET Online 17.3b**, представляющий новый большой функционал для работы с сервером.

Изначальным предназначением модуля являлось исключительная возможность сохранения прогресса игроков, но по мере обновления модификации, модуль пополнялся дополнительным функционалом.

Для работоспособности необходима специальная библиотека `xrLua.dll`. Методы из данной библиотеки используются в `saveloot.lua`

## Функционал сценария

На текущий момент saveloot.lua поддерживает:

* Профили игроков
* Пароли
* Сохранение прогресса
* Счётчик смертей
* Выброс
* Безопасные зоны
* Проверку конфигурации игроков
* Паковщик патронов
* Рекламный менеджер

* Уничтожение предметов
* Игнорирование сохранения предметов
* Режим "Зомбированных"
* Античит
* Проверку денежных транзакций
* Реавторизацию

## Профиль игрока

Профиль игрока - это специальный файл идущий в формате `.lua` таблицы `*_inventory.lua`, находящийся в директории `$app_data_root$\accounts`. В файле содержится определённая информация об игроке из списка:

```
$app_data_root$/accounts
```

### Структура данных:

| Наименование | Код                             |
| ------------ | ------------------------------- |
| Профиль      | *_inventory.lua                 |
| Пароль       | mp_actor["password"] = password |
| Прогресс     | mp_actor[number] = {}           |
| Смерти       | mp_actor["death_count"] = count |

---

## Пароль

Пароль - это параметр, создаваемый в профиле игрока. Пароль задаётся лишь единожды, изменить его может только Администратор Сервера, путём редактирования Профиля Игрока.

```lua
mp_actor["password"] = password
```

## Сохранение прогресса

Сохранение прогресса - это ряд параметров, создаваемый в профиле игрока. В качестве сохраннение прогресса представлено сохранение предметов игрока. Для их сохранения используется следующий параметр:

```lua
mp_actor[number] = {}
```

Сам параметр содержится в себе ряд сохраняемых флагов:

### Параметры предметов:

| Поле         | Описание     | Значения         |
| ------------ | ------------ | ---------------- |
| section      | ID предмета  | строка           |
| condition    | Состояние    | 0–1              |
| ammo_left    | Патроны      | ≥0               |
| ammo_elapsed | Заряжено     | ≥0               |
| ammo_type    | Тип патронов | не редактируется |
| addon_flags  | Модули       | битовая маска    |

![Сохранение прогресса](./Ak12_saveloot.png)

Для отключения и включения сохранения прогресса, в файле saveloot.lua имеется переменная need_save_loot:

### Включение/отключение:

| Параметр       | Значение     |
| -------------- | ------------ |
| need_save_loot | true / false |

---

## Счётчик смертей

Счётчик смертей - это параметр, создаваемый в профиле игрока. Позволяет вести учёт всех смертей в профиле. Учитывается любая смерть игрока. Узнать содержимое может только Администратор Сервера.

```lua
mp_actor["death_count"] = count
```

Учитывает все смерти игрока.

---

## Выброс

Данный функционал позволяет обеспечить сервер выбросом.

Выбор времени выброса, происходит через стандартный функционал XRMPE:

```lua
SURGE MANAGER: Next surge will be at %gamedate% %gametime%
```

После наступления необходимого времени, генерируется время для начала выброса. Время можно настроить в функции server_update:

```lua
local time = math.random(15000, 40000)
```

Время выводится для всех Клиентов происходит вывод в формате сообщения (send_tip):

После окончания выброса, для всех Клиентов происходит вывод в формате сообщения (send_tip):

```lua
send_tip_server(string.format("Выброс начнется через %.1f секунд!", time * 0.001))
send_tip_server("Выброс закончился!")
```

### Урон

Все выше указанные действия, в момент работы выброса, сопровождаются уроном типа radiation: За генерацию урона, в функции update_save_loot отвечают следующие параметры:

| Параметр  | Значение      |
| --------- | ------------- |
| h.type    | hit.radiation |
| h.power   | random        |
| h.impulse | 1             |

Типы урона:

* bleeding
* health
* morale
* power
* psy_health
* radiation

## Укрытие

Для того, чтобы обеспечить клиента укрытием, необходимо расположить на локации Restrictor c именем sr_surge. Имя проверяемого укрытия можно настроить в функции update_save_loot:

Restrictor с именем:

```lua
sr_surge

local zone = db.zone_by_name["sr_surge"]
```

Укрытие должно представлять собой единый Shape, расположенный на локации в местах, где необходимо укрытие. Создать такое укрытие можно в Level Editor.

---

## Безопасная зона

Безопасная зона - это Restrictor, представляющий из себя зону, в которой Клиенты в случае смерти не теряют Сохранение прогресса.

Ранее безопасная зона использовалась для сохранения прогресса, но данный функционал был вырезан.

Для того, чтобы обеспечить клиента безопасной зоной, необходимо расположить на локации Restrictor c именем sr_safe_zone. Создать такую безопасную зону можно в Level Editor.

Имя проверяемой безопасной зоны можно настроить в функции update_save_loot:

Restrictor:

```lua
sr_safe_zone

local safe_zone = db.zone_by_name["sr_safe_zone"]
```

## Проверка конфигурации игроков

Данный функционал предоставляет возможность обеспечить сервер проверкой конфигурации Клиентов, записанной в user.ltx.
Для получения команд используется bind_stalker.script. Получение команды происходит в функции mp_actor_binder:update:
Для корректного вывода требуется задать верный тип команды. Если saveloot.lua подключен, будет выполнен вывод команды.

![Проверка конфигурации игроков](./User_config_example2.png)

Пример:

```lua
self.object:give_info_portion("net_cl_icurvesize=" .. tostring(get_console():get_integer("net_cl_icurvesize")) .. "=" .. device().frame)
self.object:give_info_portion("net_cl_icurvetype=" .. tostring(get_console():get_integer("net_cl_icurvetype")) .. "=" .. device().frame)
self.object:give_info_portion("net_cl_interpolation=" .. tostring(get_console():get_float("net_cl_interpolation")) .. "=" .. device().frame)
self.object:give_info_portion("net_cl_update_rate=" .. tostring(get_console():get_integer("net_cl_update_rate")) .. "=" .. device().frame)
```


## Паковщик патронов

Основной задачей паковщика патрона является исправление проблемы с дублированием патронов, а так же исправление проблемы с разрядкой оружия.

Никаких настроек для данного функционала не имеется.

Автоматически исправляет:

* дублирование патронов
* баги разрядки


## Рекламный менеджер

Рекламный менеджер - это планировщик, используемый для вывода сообщений в чат от имени ServerAdmin, в определённое, настраиваемое время.

Настройка начинается со времени. Для этого в saveloot.lua имеется параметр agit_time_delta:

Интервал:

```lua
local agit_time_delta = 5 * 60 * 1000
```

После чего, в директории $app_data_root$, необходимо создать файл agait_manager.ltx


![Рекламный менеджер](./Agait_manager.png)

Файл:

```
agait_manager.ltx
```

Для поддержки русских символов, файл должен иметь следующую кодировку: (Windows CR LF, Windows 1251, Ins):

Далее файл заполняется необходимыми сообщениями.

В качестве разделения используется Enter. По истечению времени, планировщик выбирает случайное сообщение, и выводит его в чат от имени ServerAdmin.
