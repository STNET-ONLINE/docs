# Персональное хранилище

# [stashes] для level.ltx

Данная секция выполняет функцию ограничения доступа для пользователей. При поступлении запроса на загрузку определённого тайника сервер обращается к соответствующему файлу и проверяет заданные в нём условия. На основании результатов проверки сервер определяет доступность запрашиваемых данных с учётом текущей локации.

```ini
[stashes]
personal_stashes = main; main - техническое название тайника для Базы данных, также на локации может быть несколько тайников через ','
```

# Custom Data для InventoryBox

```ini
[personal_stash] ; секция, которая переводит InventoryBox в режим "Персонального хранилища"
enabled = true ; включен/выключен
name = main ; техническое имя согласно level.ltx
distance = 3.0 ; дистанция до взаимодействия
active = false {=actor_is_comm(bandit)} true
```
