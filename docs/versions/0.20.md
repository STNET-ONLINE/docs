# Семейство версий 0.20

**Версия 0.20** представляет собой самое масштабное обновление серверов **NET Online**. Разработка обновления велась с применением открытого исходного кода движка **X-Ray Open Multiplayer**. Это обновление представляет собой значимое нововведение, интегрируя учётные записи пользователей форума и вводя концепцию открытого мира, обогащённого сюжетом и возможностью передвижения на автотранспорте.

## Основная информация

Данное обновление было выпущено 24 июня 2024 года в рамках приватного тестирования и было разработано на платформе **X-Ray Open Multiplayer**. Также является радикальным переосмыслением направления.

### Изменения

* Интеграция учётных записей CCRN ID
* Обновлённый интерфейс с возможностью адаптации под различные разрешения
* Переходы между локациями
* Различные режимы игры (Командный бой, Открытый мир, Экспериментальный и т.д)
* Транспортные средства
* Интеграция модификации **Gunslinger Mod**
