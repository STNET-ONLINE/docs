# Семейство версий 17.0

Одно из крупнейших обновлений серверов **NET Online**. Данная версия разработана с использованием проприетарного движка **X-Ray Multiplayer Extension**. Является одной из самых долгоживущих версий из-за разработки Версии 0.20.

Данная версия имеет множество обновлений, которые исправляют ошибки и добавляют новые игровые механики, а также свою скриптовую систему «Сохранение прогресса».

За существование версии, Проект успешно сменил основное направление, обзавелся собственными Веб-ресурсами, а также было проведено несколько уникальных событий, проведена смена Администрации и правил, и под конец активной поддержки версии был организован пользовательский игровой турнир.

::: info Интересный факт
Данная версия, является единственной версией, которые использует часть контента из будущих версий, из-за того что она обновлялась параллельно с разработкой Версии 0.20
:::

Данное обновление вышло 27.07.2020, вместе с ним полноценно заработал и Форум, которые позже стал основным пристанищем Группировок и Настоящих правил Проекта
