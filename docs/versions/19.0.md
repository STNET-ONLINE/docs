# Семейство версий 19.0

Невышедшее обновление из [семейства версий 0.20](/versions/0.20). Является технической сборкой от мая 2021 года. Данная техническая версия внеса большой вклад в развитие в действующие на тот момент сервера под управлением [версии 17.0](/versions/17.0) (c 17.3b по 17.3с)

## Изменения

* Полная интеграция StCOP WP 3.5
* 3D Прицелы
* Сохранение профиля
* Возвращены квесты
* Вторая итерация машин
* Возвращены техники
* Переходы между локациями

## Памятка по запуску

1. Включаете сервер в папке `bin`
2. Заходите в игру, в поле логина:

```
Логин: nfslove777_test@gmail.com
Пароль: 2323
```

```
Логин: kuprin@1163.ru
Пароль: 112233
```

```
Логин: nfslove777
Пароль: 12345
```

3. По прямому IP, пишите - `localhost`, если конектиться ваш друг то Локальный IP или Интернет IP (В зависимости от того как вы играете)

### Добавление аккаунта

Если хотите поиграть с корешем и создать ему персональный аккаунт:
1. Переходите в `_user_dedicated_\server_data\accounts`
2. Дублируете `nfslove777_test@gmail.com` или любой другой аккаунт который там есть
3. В файле `account.ini` правите пароль и ник на нужный
