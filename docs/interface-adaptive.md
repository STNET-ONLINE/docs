# Адаптивный интерфейс

Адаптивный интерфейс — это система, позволяющая корректно отображать UI-элементы на экранах с разными разрешениями и соотношениями сторон за счёт комбинации следующих механизмов:

* анкеры (anchors)
* базовое соотношение (ratio)
* анимации

---

# 1. Базовые принципы

## 1.1 Базовое разрешение

Система опирается на фиксированную основу:

```
1024 × 768
```

Все координаты и размеры:

* задаются в этом пространстве
* затем масштабируются под реальное разрешение

---

## 1.2 Комбинирование режимов

Режимы могут использоваться одновременно:

| Механизм     | Назначение       |
| ------------ | ---------------- |
| ratio        | масштабирование  |
| anchor       | привязка к краям |
| width/height | базовый размер   |

---

# 2. Анкеры (Anchors)

## 2.1 Синтаксис

```xml
anchor="top;bottom;left;right"
```

## 2.2 Значения

| Значение | Поведение                         |
| -------- | --------------------------------- |
| -1       | игнорируется                      |
| ≥ 0      | фиксированный отступ (в пикселях) |

---

## 2.3 Логика работы

Анкеры задают ограничения относительно краёв контейнера.

### Пример

```xml
<menu anchor="100;-1;100;-1" />
```

Интерпретация:

* отступ 100 px сверху
* отступ 100 px слева
* низ и право не зафиксированы

---

## 2.4 Типовые паттерны

### Фиксация к левому верхнему углу

```xml
anchor="10;-1;10;-1"
```

---

### Растяжение по ширине

```xml
anchor="-1;-1;0;0"
```

Элемент растягивается от левого до правого края.

---

### Полное растяжение

```xml
anchor="0;0;0;0"
```

Элемент занимает весь контейнер.

---

# 3. Настоящее соотношение (Ratio)

## 3.1 Синтаксис

```xml
ratio="1"
```

---

## 3.2 Назначение

* перевод координат в базовое разрешение 1024×768
* последующее масштабирование под экран
* сохранение пропорций

---

## 3.3 Когда использовать

Использовать `ratio`, если:

* требуется точное позиционирование
* интерфейс должен быть визуально идентичен на разных разрешениях
* используется фиксированная сетка

---

## 3.4 Когда не использовать

Не рекомендуется использовать, если:

* элемент должен динамически растягиваться
* требуется гибкий layout без жёсткой привязки

---

# 4. Анимации

## 4.1 Структура

```xml
<animation>
    <key ... />
    <key ... />
</animation>
```

---

## 4.2 Принцип работы

* анимация проигрывается при отображении элемента
* используется система ключевых кадров
* значения интерполируются автоматически

---

## 4.3 Пример

```xml
<auto_static 
    ratio="1"
    x="0" 
    y="0" 
    width="208" 
    height="125"
    stretch="1">

    <texture>interface_logotype</texture>

    <animation>
        <key time="0" x="0" y="-50" a="0"/>
        <key time="0.5" x="0" y="10" a="255"/>
        <key time="1" x="0" y="0"/>
    </animation>

</auto_static>
```

---

## 4.4 Параметры `<key>`

### Позиция

```xml
x="..." y="..."
```

* относительное смещение
* применяется от начального положения

---

### Цвет и прозрачность

```xml
r="..." g="..." b="..." a="..."
```

---

### Время

```xml
time="1.2"
```

Задаёт момент времени в секундах.

---

### Задержка

```xml
delay="0.5"
```

Сдвигает начало применения ключа.
