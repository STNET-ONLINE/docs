# Менеджер Группировок

::: tip ВНИМАНИЕ
Статья об административной конфигурации.
:::

![Группировка](/PTS_LEADER.jpg)

Заполнение группировки

```ini
[Наименование группировки] ; секция согласно game_rel
admin = kuprin ; администратор группировки

members_count = 1; количество участников
member_0 = PreviewAccount; участник группировки [0 = 1]

moderators_count = 1; количество комендантов-модераторов
moderator_0 = PreviewAccount ; участники группировки, которые являются комендантами
name = stalker; наименование группировки согласно String Translate
money = 11000 ; количество денег группировки
```
